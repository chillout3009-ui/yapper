# ARC v5 — Änderungen

- Cloud-KI / OpenAI-Aufrufe vollständig aus dem Frontend entfernt.
- Account-/Supabase-Synchronisierung bleibt erhalten und ist unabhängig vom Coach.
- Coach ist jetzt lokal/regelorientiert; keine Tokens und keine API notwendig.
- Vollständiger DE/EN-Sprachumschalter.
- Deutsches UI sprachlich überarbeitet.
- Recovery-Schaltfläche mit hohem Kontrast und dunkler Textfarbe.
- Neutraler Start für neue Nutzer; keine HSPU-Vorgabe.
- Deutlich größere Übungsbibliothek für Gym, Geräte, Freihantel, Calisthenics, CrossFit, Reha/Prehab, Mobility, Laufen, Schwimmen, Fahrrad und Skaten.
- Trainingsplan-Vorlagen für alle genannten Sportarten.
- Plan-Assistent arbeitet lokal und kombiniert Vorlagen anhand von Ziel, Sportarten und Trainingstagen.
- Plan-Builder nutzt klickbare Übungs-/Intervalloptionen statt freie Übungsnamen.
- Training-Seite zeigt gespeicherte eigene Trainingseinheiten zur direkten Auswahl und Durchführung.
- Satzwerte, Wiederholungen, Gewicht, RPE, Wohlbefinden und Schmerz können während der Einheit angepasst werden.
- Zusätzliche manuelle Trainingserfassung bleibt verfügbar.
- Wochenplan weist gespeicherte Einheiten per Klick Wochentagen zu.
