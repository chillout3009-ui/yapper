# Trainingsplan importieren

1. ARC öffnen und zu **Trainingspläne** gehen.
2. Oben auf **Plan importieren** klicken.
3. Eine `.arcplan.json`-Datei auswählen.
4. Der Plan erscheint sofort unter **Meine Pläne**.
5. Über **Wochenplan** kannst du seine Einheiten Wochentagen zuweisen.
6. Unter **Training** wählst du anschließend einfach die gewünschte Einheit aus und passt die tatsächlich absolvierten Werte an.

Jeder gespeicherte Plan kann über **Exportieren** wieder als ARC-Plan-Datei gesichert werden.
