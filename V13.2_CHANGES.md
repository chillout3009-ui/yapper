# ARC v13.2 – Modality Blocks & Workout Overview

## Distanz-Tracking
- Distanz wird nur noch bei Strecken-/Ausdaueraktivitäten angeboten.
- Schwimmen und Cardio-Rudern verwenden Meter; Laufen, Radfahren, Skaten und Wandern Kilometer.
- EMOM, HIIT, Gym, CrossFit, Calisthenics, Reha und Mobility zeigen kein Distanzfeld.
- Die manuelle Eingabe blendet Distanz abhängig von der gewählten Sportart ein oder aus.

## Trainingsübersicht
- Trainingskarten öffnen vor dem Start eine vollständige Listenübersicht.
- Explizite Start-Schaltflächen starten weiterhin direkt.
- Im laufenden Workout ist die Übersicht dauerhaft über einen sticky Button erreichbar.
- Aus der Liste kann direkt zu jeder Übung / jedem Trainingsbaustein gesprungen werden.

## Getrennte Tagesblöcke
- Ein Trainingstag kann nacheinander mehrere Modalitäten enthalten, z. B. Gym → Laufen → EMOM.
- Consecutive Einträge gleicher Modalität werden als eigener Block gruppiert.
- Unterstützte Blocktypen: Gym, Laufen, Schwimmen, Rad, Skaten, Rudern, Wandern, EMOM, Tabata, HIIT, CrossFit, Calisthenics, Reha/Prehab und Mobility.
- Planeditor und Live-Workout-Picker können modalitätsübergreifend Übungen/Blöcke hinzufügen.

## Kompatibilität
- Bestehende Pläne bleiben gültig; die Blockstruktur wird aus den vorhandenen Übungs-/Intervalltypen abgeleitet.
- Supabase-Synchronisierung bleibt unverändert, da weiterhin derselbe JSON-State gespeichert wird.
