# ARC v12 changes

- Reworked the full endurance/cardio illustration set: running, swimming, cycling, inline skating, rowing and hiking.
- Endurance visuals no longer use the same generic silhouette for every workout. Sport-specific variants now show hills, trails, intervals, pull buoy, kick board, open water, cycling cadence, climbing, brick sessions, skating T-stop/slalom/cornering, rowing catch/finish and loaded hiking.
- Added a concise description to every exercise/training block in the exercise library.
- Descriptions are also shown in the exercise picker, exercise detail modal and active workout view.
- Search now also matches the short descriptions.
- Strength/calisthenics/rehab visuals from v11 remain unchanged.
